# Параметричний корпус павербанка в OpenSCAD

Параметрична 3D-модель корпусу павербанка для OpenSCAD, яка автоматично розраховує розміри корпусу та кришки на основі обраного типу та кількості акумуляторів ($S \times P$), а також габаритів та вирізів плати керування (контролера заряду).

---

## 📁 Структура проєкту

* `powerbank_case.scad` — головний файл моделі: розрахунок габаритів, формування корпусу (`powerbank_body`) та кришки (`lid`).
* `presets_batteries.scad` — бібліотека розмірів акумуляторних елементів та прев'ю батарейного блоку.
* `presets_boards.scad` — диспетчер і бібліотека вирізів для підтримуваних плат керування.
* `generated_board_presets.scad` — згенерований OpenSCAD-код на основі JSON-профілів плат (роздільні вирізи передніх портів та верхнього інтерфейсу).
* `boards/*.json` — файли конфігурації плат із точними координатами портів, дисплеїв, кнопок та кріплень:
  * `abkn_pd45w_3s.json` — модуль швидкої зарядки ABKN PD45W 3S.
  * `UFCS_PD45W.json` — модуль UFCS PD45W (калібровані допуски Type-C/Type-A та дисплея).
* `boards/images/` — оригінали фотографій плат для точної візуальної розмітки та калібрування.
* `tools/server.py` — бекенд на FastAPI/Uvicorn для завантаження, редагування, збереження плат та автогенерації SCAD-пресетів.
* `tools/board_sketcher.html` — інтерактивний візуальний редактор розмітки плат по фото з підтримкою серверного каталогу, налаштуванням зазорів (`clearance`) та прямим збереженням на сервер.
* `tools/generate_board_presets.py` — Python-генератор OpenSCAD-коду з JSON-профілів із підтримкою `offset(delta = clearance)` для полігональних вирізів.
* `requirements.txt` — Python-залежності для локального сервера (`fastapi`, `uvicorn`, `python-multipart`).

---

## 🚀 Швидкий старт

1. Відкрийте файл `powerbank_case.scad` в [OpenSCAD](https://openscad.org/).
2. У блоці **«ОСНОВНІ НАЛАШТУВАННЯ МОДЕЛІ»** оберіть тип батареї, плати та конфігурацію блоку:

```scad
battery_type = "18650";          // "18650", "liion_pouch_60x110x12", "lifepo4_pouch", "lifepo4_prismatic"
board_type   = "abkn_pd45w_3s";  // "abkn_pd45w_3s", "UFCS_PD45W"
pack_series   = 2;               // Кількість елементів S (для 18650 — вздовж Y; для pouch/prismatic — стопка по Z)
pack_parallel = 2;               // Кількість елементів P вздовж X (ширина)
```

3. Натисніть **F5** для попереднього перегляду або **F6** для фінального рендерингу (CSG комбінація).
4. Експортуйте модель у STL для 3D-друку (**F7**).

## ⚙️ Параметри моделі

Усі ключові параметри задаються у верхній частині `powerbank_case.scad`:

| Параметр | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `battery_type` | `"18650"` | Тип акумуляторів (`18650`, `liion_pouch_60x110x12`, `lifepo4_pouch`, `lifepo4_prismatic`) |
| `board_type` | `"abkn_pd45w_3s"` | Тип плати (`abkn_pd45w_3s`, `UFCS_PD45W`) |
| `pack_series` | `2` | Кількість елементів S (для 18650 — вздовж $Y$; для pouch/prismatic — стопка по $Z$) |
| `pack_parallel` | `2` | Кількість елементів P (вздовж $X$, по ширині) |
| `wall_thick` | `2.0` мм | Товщина стінок і дна корпусу |
| `tolerance` | `0.6` мм | Базовий монтажний зазор на сторону для посадки компонентів та замка кришки |
| `spacing_override` | `-1` | Проміжок між акумуляторами для вентиляції (-1: брати зі стандартного пресету) |
| `inner_xy_margin` | `4` мм | Додатковий запас по $XY$ (для дротів, стрічки, ізоляції, плати BMS) |
| `inner_z_margin` | `4` мм | Вертикальний запас над платою та батареями |
| `case_corner_radius` | `4.0` мм | Радіус заокруглення вертикальних країв корпусу (0 для гострих кутів) |
| `wire_soldering_space` | `45.0` мм | Додатковий простір у кишеньці плати для зручного паяння дротів (40-60 мм) |
| `enable_board_holders` | `true` | Горизонтальні пази в бічних стінках для фіксації плати |
| `board_thickness` | `1.1` мм | Товщина плати PCB (параметризована) |
| `board_holder_slot_depth` | `1.5` мм | Глибина горизонтального прорізу в бічну стінку |
| `board_holder_slot_offset` | `6.0` мм | Відстань від передньої стінки до прорізу |
| `enable_partition` | `true` | Увімкнути ізолюючу перегородку між кишенькою плати та батарейним блоком |
| `enable_modular_partition` | `true` | Модульна знімна перегородка у П-подібних пазах (`false` — монолітна стінка) |
| `partition_thick` | `2.4` мм | Товщина захисної вертикальної перегородки |
| `partition_groove_depth` | `1.2` мм | Глибина напрямних П-пазів у бічних стінках і дні корпусу |
| `partition_wire_hole_d` | `3.5` мм | Діаметр отворів у перегородці під силові дроти |
| `partition_nickel_slot_w` | `8.0` мм | Ширина прорізів під нікелеві стрічки |
| `partition_nickel_slot_h` | `1.5` мм | Висота/товщина прорізів під нікелеві стрічки |
| `show_partition` | `true` | Відображати перегородку при `part = "all"` |
| `enable_ventilation` | `true` | Увімкнути пасивне конвекційне охолодження (решітки) |
| `vent_type` | `"slots"` | Форма вентиляції: `"slots"` (поздовжні прорізи) або `"hex"` (стільники) |
| `vent_slot_w` | `2.0` мм | Ширина прорізів лінійної решітки |
| `vent_slot_spacing` | `2.5` мм | Крок/перемичка між вентиляційними прорізами |
| `vent_hex_radius` | `2.2` мм | Радіус осередку гексагональної стільникової решітки |
| `vent_placement` | `"sides"` | Розташування решіток: `"sides"` (боки), `"bottom"` (дно), `"both"` |
| `enable_snap_fit` | `true` | Увімкнути надійні механічні защіпки кришки (Snap-fit) |
| `snap_ridge_depth` | `0.5` мм | Глибина виступу защіпки для безінструментного замикання |
| `enable_modular_front_panel` | `true` | Модульна знімна передня панель у пазах (`false` — монолітний корпус) |
| `front_panel_thick` | `wall_thick` | Товщина знімної лицьової панелі (безеля) |
| `front_panel_groove_depth` | `1.2` мм | Глибина напрямних U-пазів у стінках і дні корпусу |
| `show_front_panel` | `true` | Відображати знімну панель при `part = "all"` |
| `panel_gap` | `8` мм | Відступ деталей на столі друку |
| `part` | `"all"` | Селектор деталей для STL експорту: `"all"`, `"body"`, `"lid"`, `"front_panel"`, `"partition"`, `"assembly"` |
| `show_lid` | `true` | Відображати кришку поруч із корпусом (для експорту окремо встановіть `false`) |
| `show_battery` | `false` | Відображати напівпрозоре прев'ю батарейного блоку всередині корпусу |
| `lid_gap` | `8` мм | Відстань між корпусом і кришкою на столі перегляду |
| `lid_thick` | `wall_thick` | Товщина верхньої стінки кришки (кришка залишається пласкою) |
| `lid_lip_depth`| `2.5` мм | Глибина внутрішнього центруючого бортика кришки для фіксації в корпусі |

## 📐 Геометрична логіка та компонування

Модель використовує поздовжнє послідовне компонування (Front-to-Back Stacking):
1. **Кишенька плати керування (спереду, вздовж $Y$):**
   * Розміщується безпосередньо біля передньої панелі корпусу ($Y \in [0 \dots \text{board\_pocket\_length}]$).
   * Довжина відсіку: $\text{board\_pocket\_length} = \text{board\_length} + \text{wire\_soldering\_space} + 2 \times \text{tolerance}$.
   * Забезпечує $40\dots 60$ мм вільного простору перед перегородкою для зручного укладання та паяння силових і сигнальних дротів.
2. **Захисна вертикальна перегородка (Partition Wall):**
   * У режимі `enable_modular_partition = true` перегородка формується як окрема пласка пластина `partition_panel()`, яка засувається вертикально у внутрішні П-подібні пази корпусу (глибиною `partition_groove_depth = 1.2` мм).
   * Забезпечує легкий 3D-друк плазом на столі друку без підтримок з ідеальною точністю отворів під силові дроти ($\varnothing 3.5$ мм) та нікелеві стрічки ($8.0 \times 1.5$ мм).
   * **Фіксація кришкою:** поперечний виступ на внутрішньому боці кришки притискає верхній торець перегородки при закриванні, унеможливлюючи її деренчання чи зміщення.
   * При `enable_modular_partition = false` генерується монолітна стінка `partition_thick`.
3. **Батарейний відсік (позаду перегородки, вздовж $Y$):**
   * **18650 (циліндричні):** розташовуються у площині $XY$ ($X = \text{pack\_parallel}$, $Y = \text{pack\_series}$, $Z = 1$). Циліндри точно центровані в додатних координатах ($+X/2, +Z/2, \text{rotate}([-90,0,0])$).
   * **Pouch / Prismatic (пласкі пакети):** пакети послідовного з'єднання $\text{pack\_series}$ складаються вертикально в стопку вздовж $Z$ із проміжками `spacing` для циркуляції повітря й охолодження, а паралельні $\text{pack\_parallel}$ розміщуються по ширині $X$.
   * **Габарити батарейного блоку:**
     * $X$ (ширина): $\text{cells\_x} \times \text{battery\_width} + \max(\text{cells\_x} - 1, 0) \times \text{spacing}$
     * $Y$ (довжина): $\text{cells\_y} \times \text{battery\_length} + \max(\text{cells\_y} - 1, 0) \times \text{spacing}$
     * $Z$ (висота): $\text{cells\_z} \times \text{battery\_height} + \max(\text{cells\_z} - 1, 0) \times \text{spacing}$
4. **Загальний внутрішній простір:**
   * $\text{inner\_x} = \max(\text{pack\_width}, \text{board\_width}) + 2 \times \text{tolerance} + \text{inner\_xy\_margin}$
   * $\text{inner\_y} = \text{board\_pocket\_length} + \text{part\_thick} + \text{pack\_length} + \text{inner\_xy\_margin}$
   * $\text{inner\_z} = \max(\text{pack\_height}, \text{board\_height}) + \text{inner\_z\_margin}$
5. **Знімна передня панель у напрямних пазах (Modular Slide-in Bezel):**
   * У режимі `enable_modular_front_panel = true` на передній стінці корпусу формується вікно з U-подібними напрямними пазами (глибиною `front_panel_groove_depth = 1.2` мм).
   * Верхній торець пазів залишається відкритим, дозволяючи засувати панель вертикально зверху вниз.
   * Панель (`front_panel`) друкується окремо плазом на столі друку ($XY$-площина), забезпечуючи гладкі контури портів, ідеальні мости та відсутність підтримок.
   * **Замкове блокування кришкою:** внутрішній передній виступ кришки заходить у корпус безпосередньо над верхнім торцем панелі, жорстко фіксуючи її від випадання чи люфту при підключенні кабелів.
6. **Заокруглення корпусу та пласка кришка:**
   * Вертикальні ребра корпусу мають параметричне заокруглення `case_corner_radius = 4.0` мм для комфортного утримання в руці.
   * Кришка друкується як пласка пластина (flat plate) із повторенням контуру корпусу та внутрішнім шипом для фіксації в корпусі.
7. **Багатопроекційні вирізи (Front vs Top):**
   * Елементи з `"face": "front"` (порти, а також екран/кнопка для плати `abkn_pd45w_3s`) вирізаються на знімній передній панелі (`front_panel`) або монолітній передній стінці корпусу (`powerbank_body`).
   * Елементи з `"face": "top"` (дисплеї/кнопки для класичних плат) вирізаються у кришці (`lid`).
   * Для плат на зразок `abkn_pd45w_3s` кришка залишається повністю суцільною, захищаючи відсік плати від пилу та вологи.

## 🖨️ Експорт деталей для 3D-друку (`part`)

Змінна `part` дозволяє обрати потрібний режим рендерингу для покрокового експорту в окремі STL-файли:
* `part = "all"` — розміщення корпусу, кришки, передньої панелі та перегородки на столі перегляду.
* `part = "body"` — рендеринг тільки основного корпусу для експорту в `body.stl`.
* `part = "lid"` — рендеринг тільки верхньої кришки для експорту в `lid.stl`.
* `part = "front_panel"` — рендеринг пласкої передньої панелі на площині $Z=0$ для експорту в `front_panel.stl`.
* `part = "partition"` — рендеринг пласкої перегородки на площині $Z=0$ для експорту в `partition.stl`.
* `part = "assembly"` — візуалізація повністю зібраного павербанка (корпус + встановлена панель + перегородка + закрита кришка) для перевірки посадки та зазорів.

## 🛠️ Робота з платами та візуальним редактором (Board Sketcher)

### Спосіб 1: Через веб-сервер та Board Sketcher (Рекомендовано)
1. Встановіть залежності та запустіть бекенд-сервер:
   ```bash
   pip install -r requirements.txt
   uvicorn tools.server:app --port 8000 --reload
   ```
2. Відкрийте браузер за адресою [http://localhost:8000/](http://localhost:8000/).
3. Виберіть потрібну плату (наприклад, `abkn_pd45w_3s` або `UFCS_PD45W`) у випадаючому списку зверху — фото плати, масштаб, контури портів та дисплея завантажаться автоматично.
4. Налаштуйте координати, розміри або індивідуальні зазори (`clearance`) для кожного порту у панелі властивостей праворуч:
   * **USB Type-C:** рекомендований зазор `0.5 мм` для вільного входження штекера.
   * **USB Type-A:** рекомендований зазор `0.35 мм`.
   * **Дисплеї та полігони:** автоматичний розширений офсет `offset(delta = clearance)` (0.2–0.4 мм).
5. Натисніть **«💾 Зберегти на сервер»** — сервер оновить `boards/<id>.json`, збереже фото в `boards/images/` та автоматично регенерує `generated_board_presets.scad`.

### Спосіб 2: Локальний офлайн-режим та ручна генерація OpenSCAD
1. Відкрийте `tools/board_sketcher.html` напряму у браузері.
2. Завантажте фото, відкалібруйте масштаб і створіть контури.
3. Експортуйте файл `boards/<id>.json`.
4. Згенеруйте OpenSCAD-код вручну:
   ```bash
   python3 tools/generate_board_presets.py
   ```

Скрипт оновить `generated_board_presets.scad` із готовими функціями `board_params_<id>`, `cutouts_front_<id>`, `cutouts_top_<id>` та оновленими диспетчерами.

## 💡 Поради для 3D-друку та збирання

* **Матеріали:** Рекомендується друкувати з **PETG**, **ABS** або **ASA** через їхню підвищену термостійкість та механічну міцність порівняно з PLA.
* **Орієнтація при друку:** Корпус і кришка друкуються плоскою стороною до столу ($Z=0$), без потреби у підтримках.
* **Калібрування зазорів:** Перед фінальним друком надрукуйте тестовий зріз або перші 5 мм кришки для перевірки `tolerance` під ваш принтер і пластик.
* **Електрична безпека:**
  * Завжди передбачайте ізоляцію між акумуляторними елементами та платою (каптоновий скотч, текстоліт або ізоляційні прокладки).
  * Параметр `inner_xy_margin` і `inner_z_margin` збільшуйте, якщо використовується товстий силіконовий кабель або зовнішня плата BMS.
