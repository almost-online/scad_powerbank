# AGENTS.md — Інструкції для AI-асистентів та розробників

Цей документ містить правила архітектури, опис кодової бази, геометричні конвенції та інструкції для AI-агентів і розробників, які працюють із цим репозиторієм.

---

## 🧭 Загальний огляд проєкту

Проєкт є параметричним генератором корпусів павербанків для **OpenSCAD**. Він дозволяє гнучко генерувати 3D-моделі корпусу та кришки під будь-які комбінації акумуляторів ($S \times P$) та плат керування.

### Технологічний стек
* **OpenSCAD** — 3D CAD моделювання через CSG (Constructive Solid Geometry).
* **Python 3 / FastAPI / Uvicorn** — REST API бекенд (`tools/server.py`) для каталогу плат, фото та збереження.
* **JSON** — декларативний опис геометрії та компонентів плат (`boards/*.json`).
* **HTML5 Canvas / Vanilla JS** — інтерактивний візуальний редактор розмітки плат по фото (`tools/board_sketcher.html`).

## 📐 Геометрична логіка та правила моделювання

### 1. Базова система координат
* Використовується права декартова система:
  * $+X$ — ширина (вправо)
  * $+Y$ — довжина / глибина (назад, від передньої панелі)
  * $+Z$ — висота (вгору)
* Початок координат $(0,0,0)$ для основного корпусу розташований у лівому нижньому передньому зовнішньому куті.

### 2. Поздовжнє компонування (Front-to-Back Stacking), перегородка та орієнтація батарей
* **Спереду ($Y \in [0 \dots \text{board\_pocket\_length}]$):** Відсік (кишенька) плати керування:
  * Довжина відсіку: $\text{board\_pocket\_length} = \text{board\_length} + \text{wire\_soldering\_space} + 2 \times \text{tolerance}$, де $\text{wire\_soldering\_space} = 40\dots 60$ мм виділено під зручний монтаж та паяння силових дротів.
* **Перегородка ($Y \in [\text{board\_pocket\_length} \dots \text{board\_pocket\_length} + \text{part\_thick}]$):**
  * У модульному режимі (`enable_modular_partition = true`) перегородка є знімною пластиною (`partition_panel`), що вставляється у П-подібні напрямні пази лівої, правої стінок та дна корпусу.
  * Панель перегородки друкується плазом на столі друку ($XY$-площина), містить круглі прохідні отвори під дроти ($\varnothing 3.5$ мм) та кутові пази під нікелеві стрічки ($8.0 \times 1.5$ мм), а зверху жорстко притискається поперечним бортиком кришки.
* **Позаду ($Y \in [\text{board\_pocket\_length} + \text{part\_thick} \dots \text{inner\_y}]$):** Акумуляторний блок:
  * **18650 (циліндричні):** розташовуються у площині $XY$ ($X = \text{pack\_parallel}$, $Y = \text{pack\_series}$, $Z = 1$). Циліндри центровані в додатних координатах ($+W/2$ по $X$, $+H/2$ по $Z$, вісь вздовж $+Y$).
  * **Pouch / Prismatic (пласкі пакети):** елементи послідовного з'єднання $\text{pack\_series}$ складаються вертикально по осі $Z$ ($Z = \text{pack\_series}$, $X = \text{pack\_parallel}$, $Y = 1$) із зазорами `spacing` для вентиляції та циркуляції повітря.
* **Заокруглення корпусу та кришка:**
  * Вертикальні ребра корпусу мають параметричне заокруглення `case_corner_radius = 4.0` мм для ергономіки та якісного 3D-друку.
  * Кришка моделюється як пласка пластина (flat plate), що зберігає форму контуру корпусу.
* **Формули простору:**
  * $\text{pack\_width} = \text{cells\_x} \times \text{battery\_width} + \max(\text{cells\_x} - 1, 0) \times \text{spacing}$
  * $\text{pack\_length} = \text{cells\_y} \times \text{battery\_length} + \max(\text{cells\_y} - 1, 0) \times \text{spacing}$
  * $\text{pack\_height} = \text{cells\_z} \times \text{battery\_height} + \max(\text{cells\_z} - 1, 0) \times \text{spacing}$
  * $\text{inner\_x} = \max(\text{pack\_width}, \text{board\_width}) + 2 \times \text{tolerance} + \text{inner\_xy\_margin}$
  * $\text{inner\_y} = \text{board\_pocket\_length} + \text{part\_thick} + \text{pack\_length} + \text{inner\_xy\_margin}$
  * $\text{inner\_z} = \max(\text{pack\_height}, \text{board\_height}) + \text{inner\_z\_margin}$

### 3. Бічні тримачі плати (PCB Side Holders)
* **Призначення:** Надійна фіксація плати керування всередині відсіку, запобігання вертикальному зміщенню та вібро-розхитуванню.
* **Параметризація:**
  * `enable_board_holders = true` — увімкнути вбудовані тримачі.
  * `board_holder_thick = 1.2` мм — товщина тримача.
  * `board_holder_width = 4.0` мм — ширина тримача вздовж Y.
  * `board_holder_slot_depth = 1.5` мм — глибина прорізу під текстоліт.
  * `board_holder_slot_start = 5.0` мм — відстань від передньої панелі до початку прорізу.
  * `board_holder_slot_gap = 0.2` мм — додатковий зазор прорізу над товщиною плати.
* **Геометрія:** Два бічних тримачі (лівий та правий), що встановлюються від дна відсіку вгору на `inner_z`. Проріз центрований по висоті для вільного входження текстоліту товщиною ~1.1 мм.
* **Інтеграція:** Тримачі додаються до корпусу через `union()` у модулі `powerbank_body()`, формуючи монолітну структуру без додаткових деталей.

### 4. Багатопроекційні модулі вирізів (Front vs Top vs Side)
* **Передні/бокові вирізи (`draw_board_front_cutouts`):** віднімаються від `powerbank_body`. Включають порти та елементи з `"face": "front"` (наприклад, екран і кнопку для `abkn_pd45w_3s`).
* **Верхні вирізи інтерфейсу (`draw_board_top_cutouts`):** віднімаються від `lid` тільки якщо мають `"face": "top"`.
* Це забезпечує чисте CSG-дерево, суцільну кришку для торцевих плат (`abkn_pd45w_3s`) та усуває паразитні пропили.

### 5. Уникнення колізій та Z-Fighting у CSG
* При операціях `difference()` вирізи **завжди** повинні виходити за межі тіла щонайменше на $1$–$2$ мм (наприклад, `translate([..., -1, ...])` з додаванням $+2$ мм до довжини). Це запобігає виникненню нульових поверхонь і артефактів рендерингу (Z-fighting / non-manifold geometry).

### 6. Пасивне тепловідведення (Ventilation Lattice)
* Для високопотужних плат (PD 45W+) та літієвих збірок передбачено параметричні вентиляційні решітки (`enable_ventilation = true`).
* Підтримуються два типи решіток:
  * `vent_type = "slots"` — поздовжні пази із заокругленими кінцями (`vent_slot_w`, `vent_slot_spacing`).
  * `vent_type = "hex"` — стільникові гексагональні структури (`vent_hex_radius`, `vent_hex_wall`).
* Розміщення решіток (`vent_placement = "sides" | "bottom" | "both"`) автоматично враховує габарити відсіку плати та батарейного блоку з відступами від силових кутів.

### 7. Механічна фіксація Snap-Fit
* Фіксація кришки може підсилюватись параметричними защіпками (`enable_snap_fit = true`).
* Складається з клиноподібних виступів `snap_ridge_depth = 0.5` мм на бортику кришки та відповідних внутрішніх канавок у стінках корпусу, що забезпечує надійне замикання без потреби в гвинтах чи клеї.

### 8. Модульні знімні елементи (Bezel та Partition) у П-подібних пазах
* **U-подібні напрямні пази в корпусі (`enable_modular_front_panel = true`, `enable_modular_partition = true`):**
  * Бічні та нижній пази заглиблюються в стінки на `min(wall_thick / 2, groove_depth)` (за замовчуванням 1.0–1.2 мм).
  * Ширина паза в напрямку $Y$ становить товщину відповідної деталі плюс `tolerance`.
  * Верхній торець пазів відкритий по всій висоті, що усуває нависання та мости при друку основного корпусу.
* **Геометрія та орієнтація деталей (`front_panel`, `partition_panel`):**
  * Ширина: $W = \text{inner\_x} + 2 \times \text{groove\_d} - 2 \times \text{tolerance}$.
  * Висота: $H = \text{inner\_z} + \text{groove\_d} - \text{lid\_lip\_depth} - \text{tolerance}$.
  * Для друку деталі розміщуються плазом у площині $XY$ ($Z \in [0 \dots \text{thick}]$) для бездоганної якості отворів без підтримок.
* **Блокування кришкою (`lid`):**
  * Внутрішній передній та поперечний бортики кришки заходять безпосередньо над верхніми торцями передньої панелі та перегородки, повністю виключаючи їхній вертикальний рух або люфт під час користування.
* **Селектор експорту (`part`):**
  * `part = "all" | "body" | "lid" | "front_panel" | "partition" | "assembly"`.

## 📋 Правила роботи з платами (Board Presets)

1. **Єдине джерело правди — `boards/*.json`:**
   * Не хардкодьте координати вирізів безпосередньо в `presets_boards.scad`.
   * При додаванні нової плати або зміні розмірів/портів обов'язково редагуйте або створюйте відповідний `boards/<id>.json`.

2. **Формат JSON-профілю плати:**
   ```json
   {
     "id": "unique_board_id",
     "name": "Human Readable Name",
     "units": "mm",
     "board": { "width": 55, "length": 65, "height": 16 },
     "ports": [
       { "id": "usb_a", "type": "usb_a", "edge": "front", "offset": 8, "width": 14, "height": 7 }
     ],
     "displays": [
       { "id": "lcd", "face": "top", "x": 15, "y": 10, "width": 25, "length": 12, "clearance": 0.4 }
     ],
     "buttons": [
       { "id": "power", "face": "top", "x": 27.5, "y": 28, "diameter": 6, "clearance": 0.4 }
     ],
     "indicators": []
   }
   ```

3. **Веб-сервер та генерація OpenSCAD коду:**
   - Для інтерактивної розмітки запустіть бекенд:
     ```bash
     uvicorn tools.server:app --port 8000 --reload
     ```
   - При збереженні плати з `board_sketcher.html` сервер автоматично записує `boards/<id>.json`, фото в `boards/images/` та запускає генератор `tools/generate_board_presets.py`.
   - Для ручної генерації без сервера запустіть:
     ```bash
     python3 tools/generate_board_presets.py
     ```
   - Скрипт регенерує `generated_board_presets.scad` із підтримкою `offset(delta = clearance)` для полігонів.

## 🔍 Чек-лист валідації змін для AI-агента

Перед завершенням завдання завжди перевіряйте:
- [ ] **Фізична валідність розмірів плати:** Сума ширин портів та відступів на грані не повинна перевищувати ширину плати (`board.width`).
- [ ] **Відсутність колізій портів:** Координати та розміри сусідніх роз'ємів не повинні перекриватися (якщо це не комбінований/двоповерховий роз'єм).
- [ ] **Коректність синтаксису OpenSCAD:** Відсутність пропущених крапок з комою, збіг відкриваючих і закриваючих дужок `{}`, `[]`, `()`.
- [ ] **Синхронізація пресетів:** Усі типи плат у `powerbank_case.scad` підтримуються в `presets_boards.scad` та `generated_board_presets.scad`.
- [ ] **Допуски для друку (`tolerance`):** Переконайтеся, що всі з'єднання (кришка, замок `lid_lip_depth`, порти) мають параметризовані зазори.
